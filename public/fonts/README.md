# Manrope

`manrope-latin-variable.woff2` is the official Google Fonts Latin subset of Manrope, downloaded October 16, 2026. It supports normal style with variable weights 200–800. The file is 24,576 bytes and is self-hosted to avoid runtime requests to a third-party font service.

- Family: https://fonts.google.com/specimen/Manrope
- Source CSS: https://fonts.googleapis.com/css2?family=Manrope:wght@200..800&display=swap
- Download: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSvfedN4.woff2
- License source: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt
- License: SIL Open Font License 1.1, included in `Manrope-OFL.txt`.

Use `font-weight: 200 800` and `font-display: swap` in the `@font-face` declaration. The UI uses English/Latin text; other scripts should fall back to the system font.
